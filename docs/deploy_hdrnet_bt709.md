# HDRNet BT.709 部署方案

## 概述

HDRNet BT.709 版本是一个基于 Bilateral Grid 的图像增强网络，用于 SDR 到 HDR 的转换。
部署分为三个核心模块：

1. **Grid 网络 (LowResNet)** - 生成 32×32×16×12 的仿射系数网格
2. **Guide 计算** - 用 RGB 计算 BT.709 亮度作为三线性插值的索引
3. **仿射变换 (SliceApply)** - 三线性插值 + 仿射变换得到输出 RGB

---

## 模块一：Grid 网络 (LowResNet)

### 功能
输入下采样图像，输出 Bilateral Grid 的仿射系数。

### 输入
- **尺寸**: 固定 512×512（训练配置）或 256×256（原始配置）
- **通道**: 3 (RGB)
- **范围**: [0, 1]

### 输出
- **形状**: `(B, 16, 32, 32, 12)`
  - `B`: batch size
  - `16`: intensity bins（亮度分档）
  - `32×32`: 空间网格
  - `12`: 每个网格点的仿射系数（3×3 矩阵 + 3 bias）

### 网络结构

```
输入 (B, 3, 512, 512)
    │
    ▼
┌─────────────────────────────────────────────────────────────┐
│                    Splat 分支（下采样）                       │
│  Conv(3→256) → Conv(256→512) → Conv(512→1024)              │
│  每层 stride=2, LeakyReLU(0.2)                              │
│  输出: (B, 1024, 64, 64)                                    │
└─────────────────────────────────────────────────────────────┘
    │
    ├──────────────────────────────────┐
    ▼                                  ▼
┌────────────────────────┐    ┌────────────────────────────────┐
│    Global 分支          │    │      Local 分支                 │
│ 继续下采样到 4×4        │    │  保持 64×64 分辨率              │
│ → AdaptiveAvgPool(1)   │    │  Conv(1024→128, 1×1)           │
│ → FC(16384→512)        │    │  → Conv(128→128, 3×3)          │
│ → FC(512→128)          │    │  → Conv(128→128, 3×3)          │
│ → FC(128→128)          │    │  输出: (B, 128, 64, 64)        │
│ 输出: (B, 128, 1, 1)   │    │                                │
└────────────────────────┘    └────────────────────────────────┘
    │                                  │
    │    ┌─────────────────────────────┘
    ▼    ▼
┌─────────────────────────────────────────────────────────────┐
│                    Fusion + Prediction                       │
│  local_feat + global_feat → ReLU                            │
│  → Conv(128→192, 1×1)  # 16 bins × 12 coeffs = 192        │
│  输出: (B, 192, 64, 64)                                     │
└─────────────────────────────────────────────────────────────┘
    │
    ▼
┌─────────────────────────────────────────────────────────────┐
│                    Reshape                                   │
│  (B, 192, 64, 64) → (B, 16, 12, 64, 64)                   │
│  → permute → (B, 16, 64, 64, 12)                           │
│  # 注意：实际输出是 32×32，这里 64 需要确认配置              │
└─────────────────────────────────────────────────────────────┘
    │
    ▼
输出: (B, 16, 32, 32, 12)
```

### 12 个仿射系数含义

```
[a0  a1  a2  a3 ]   [R_in]   [R_out]
[a4  a5  a6  a7 ] × [G_in] = [G_out]
[a8  a9  a10 a11]   [B_in]   [B_out]
                     [ 1  ]

其中：
- a0-a2: R 通道的 RGB 混合系数
- a3: R 通道的 bias
- a4-a6: G 通道的 RGB 混合系数
- a7: G 通道的 bias
- a8-a10: B 通道的 RGB 混合系数
- a11: B 通道的 bias
```

### 部署要点

1. **固定输入尺寸**: 必须 resize 到固定尺寸（512×512 或 256×256）
2. **量化友好**: 网络结构简单，主要是 Conv + LeakyReLU
3. **输出归一化**: 输出系数无固定范围，需要根据实际分布确定量化范围

## 模块二：Guide 计算（BT.709 亮度）

### 功能
计算输入图像的 BT.709 亮度，作为三线性插值的 intensity 索引。

### 公式

```
Y = 0.2126 × R + 0.7152 × G + 0.0722 × B
```

### 输入
- **尺寸**: 原图尺寸 (H, W)，如 1920×1080 或 3840×2160
- **通道**: 3 (RGB)
- **范围**: [0, 1]

### 输出
- **形状**: `(B, 1, H, W)`
- **范围**: [0, 1]

### 部署要点

1. **无参数**: 纯固定系数计算，无需学习
2. **全分辨率**: 在原始分辨率上计算，不需要下采样
3. **精度要求**: 系数需要高精度（float32 或更高），避免亮度计算误差

### 代码实现

```python
# BT.709 系数（固定）
coeffs = [0.2126, 0.7152, 0.0722]  # R, G, B

# 计算亮度
Y = 0.2126 * R + 0.7152 * G + 0.0722 * B
```

## 模块三：三线性插值 + 仿射变换 (SliceApply)

### 功能
根据 Guide 值在 Bilateral Grid 中进行三线性插值，得到每个像素的仿射系数，然后对输入 RGB 进行仿射变换。

### 输入
1. **Grid**: `(B, 16, 32, 32, 12)` - 仿射系数网格
2. **Guide**: `(B, 1, H, W)` - BT.709 亮度图
3. **X**: `(B, 3, H, W)` - 原始输入 RGB

### 输出
- **形状**: `(B, 3, H, W)` - 变换后的 RGB
- **范围**: [0, 1]（clamp 后）

### 三线性插值原理

对于每个输出像素 (i, j)，需要插值 8 个网格顶点：

```
空间坐标:
  x = j / W × (Wg - 1)  # Wg = 32
  y = i / H × (Hg - 1)  # Hg = 32

Intensity 坐标:
  z = Y[i,j] × (D - 1)  # D = 16, Y 是 BT.709 亮度

8 个顶点:
  (x0, y0, z0), (x1, y0, z0), (x0, y1, z0), (x1, y1, z0)
  (x0, y0, z1), (x1, y0, z1), (x0, y1, z1), (x1, y1, z1)

其中 x0 = floor(x), x1 = min(x0+1, Wg-1), 同理 y, z

权重:
  w000 = (1-dx) × (1-dy) × (1-dz)
  w001 = dx × (1-dy) × (1-dz)
  w010 = (1-dx) × dy × (1-dz)
  w011 = dx × dy × (1-dz)
  w100 = (1-dx) × (1-dy) × dz
  w101 = dx × (1-dy) × dz
  w110 = (1-dx) × dy × dz
  w111 = dx × dy × dz

插值结果:
  coeff = Σ(w_xyz × grid[z, y, x])  # 12 个系数
```

### 仿射变换

```
# coeff 形状: (B, 12, H, W)
# 拆分为 3×3 矩阵 A 和 3 维 bias b

A = coeff[:, :9, :, :].reshape(B, 3, 3, H, W)
b = coeff[:, 9:, :, :].reshape(B, 3, 1, H, W)
x_vec = x.reshape(B, 3, 1, H, W)

# 矩阵乘法 + bias
out = (A × x_vec).sum(dim=2) + b.squeeze(2)

# 等价于:
# R_out = a0×R + a1×G + a2×B + a3
# G_out = a4×R + a5×G + a6×B + a7
# B_out = a8×R + a9×G + a10×B + a11
```

### 部署要点

1. **全分辨率计算**: 三线性插值需要在原图每个像素上执行
2. **边界处理**: 坐标需要 clamp 到合法范围
3. **内存优化**: 可以分块处理，避免一次性计算全图
4. **量化注意**: 插值权重和系数都需要合理量化范围

### 优化建议

```
对于硬件部署，可以：
1. 将 32×32×16 的 grid 加载到片上 SRAM
2. 每个像素只需要 8 次 gather + 加权求和
3. 仿射变换是简单的乘加运算
4. 可以流水线化：插值 → 仿射变换 → 输出
```

## 完整推理流程

```
输入图像 (H, W, 3) RGB in [0, 1]
    │
    ├──→ Resize 到 (512, 512)
    │         │
    │         ▼
    │    ┌─────────────┐
    │    │  LowResNet  │  模块一：Grid 网络
    │    └─────────────┘
    │         │
    │         ▼
    │    Grid (16, 32, 32, 12)
    │         │
    ├──→ BT.709 亮度计算
    │         │
    │         ▼
    │    Guide (1, H, W)  模块二：Guide 计算
    │         │
    ├──→ 原始 RGB (3, H, W)
    │         │
    │         ▼
    │    ┌─────────────┐
    │    │ SliceApply  │  模块三：三线性插值 + 仿射变换
    │    └─────────────┘
    │         │
    │         ▼
    │    Output (3, H, W)
    │         │
    ▼         ▼
    Clamp 到 [0, 1]
    │
    ▼
输出图像 (H, W, 3) RGB in [0, 1]
```

## 量化部署建议

### Grid 网络
- **权重**: INT8 量化，参考训练时的分布
- **激活**: INT8，LeakyReLU 可以用 LUT 近似
- **输入/输出**: FP16 或 INT8

### Guide 计算
- **系数**: FP16（0.2126, 0.7152, 0.0722 需要高精度）
- **计算**: 3 次乘法 + 2 次加法

### SliceApply
- **Grid 系数**: FP16 或 INT8，需要根据实际分布确定量化范围
- **插值权重**: FP16（0-1 范围）
- **仿射变换**: INT8 乘加运算

### 内存占用估算

```
Grid: 16 × 32 × 32 × 12 × 2 bytes (FP16) = 384 KB
Guide: H × W × 2 bytes (FP16)
输入/输出: H × W × 3 × 2 bytes (FP16)

对于 4K (3840×2160):
  Guide: ~16 MB
  输入/输出: ~50 MB
```

## 关键参数

| 参数 | 值 | 说明 |
|------|-----|------|
| grid_H | 32 | 空间网格高度 |
| grid_W | 32 | 空间网格宽度 |

| coeffs | 12 | 每个网格点的仿射系数数量 |

## 与原始 HDRNet 的差异

| 特性 | 原始 HDRNet | BT.709 版本 |
|------|------------|------------|
| Guide 计算 | 可学习的单通道网络 | 固定 BT.709 公式 |
| Guide 参数 | 有 | 无 |
| 可导出 3D LUT | 否（空间变化） | 否（空间变化） |
| 部署复杂度 | 中 | 低（Guide 部分简化） |

---

## 总结

HDRNet BT.709 版本的部署优势：
1. **Guide 部分无参数**：固定公式，无需存储权重
2. **计算简单**：主要是 Conv、三线性插值、仿射变换
3. **量化友好**：没有复杂的归一化层
4. **流水线化**：三个模块可以顺序执行

主要挑战：
1. **三线性插值**：需要在原图每个像素上执行，计算量大
2. **Grid 存储**：384 KB 需要片上 SRAM
3. **全分辨率处理**：4K 输入需要分块处理
